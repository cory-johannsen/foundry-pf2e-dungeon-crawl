# AI Actor Self-Effect Widening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace #910's "stances + Rage" self-effect allowlist with a derived, data-driven eligibility filter covering every one-action/free self-effect feat/action the module can safely apply unattended, plus a reviewed denylist, a deterministic relevance-ordered cap, and end-of-combat cleanup for effects that outlive the encounter.

**Architecture:** `computeSelfEffectVocabularyEntries` (per #910's plan) gains five new deterministic exclusion checks against the *linked effect's* own rule elements and duration, a reviewed slug denylist, and a relevance-sort-then-cap step. A new pure `scripts/self-effect-summary.mjs` builds each surviving entry's `effectSummary`/`durationLabel` for the reasoning model. Execution (`executeSelfEffectFeat`, per #910's plan) tags every effect it creates; a new combat-end cleanup removes tagged effects whose own duration is `unlimited`.

**Tech Stack:** Vanilla JS (ES modules), Foundry VTT v14 API, PF2e system API, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-08-ai-actor-self-effect-widening-design.md`

## Global Constraints

- **Hard dependency: #910's own plan (`docs/superpowers/plans/2026-10-08-ai-actor-feat-actions.md`) must be fully implemented and merged first**, and in turn #909's. Confirmed live as of this plan's writing: `scripts/dungeon-combat.mjs`'s `computeSelfEffectVocabularyEntries` does not exist in the codebase yet.
- **The denylist is real, reviewed data produced during this plan's own writing, not a placeholder for later.** Per the spec's own resolved Decision 1 ("the denylist ships as reviewed data"), this plan's author queried the live `pf2e.feats-srd`/`pf2e.actionspf2e` compendia directly, classified every one-action/free self-effect candidate (156 non-stance, non-Rage items — the spec's own 139-survivor figure minus 51 stances minus Rage), and the owner reviewed the 87 survivors and approved a 10-slug denylist (Task 1) — confirmed live, zero unresolved `selfEffect` UUIDs across the full candidate set.
- **The audit-test fixture (Task 6) is this same live-queried classification, committed as real data**, not regenerated by whoever implements this plan — regenerating it risks silent methodology drift from a second, independent re-derivation.
- Follow this repo's existing per-file `const MODULE_ID = "pf2e-dungeon-crawl";` convention.
- Bump `module.json`'s `version` as part of this work (minor bump; check the current value at the final task — #909/#910/#911's own plans will each have already consumed a bump by the time this one executes).

## Review Focus

- An effect with an unresolved `ChoiceSet`, a `GrantItem` rule, a `TokenMark`/target-dependent rule, no rules at all, or an `hours`/`days` duration must be excluded even when it otherwise looks like a normal buff — these are the five checks the whole feature's safety rests on.
- A denylisted slug must be excluded even though it passes every other check — the denylist is a final gate, not a replacement for the derived filter.
- More than 12 eligible entries in one turn must be truncated to the 12 most relevant (attack/damage/speed-modifying entries ahead of resistance-only ahead of everything else), deterministically — never a different 12 on a repeated call with the same input.
- An `unlimited`-duration effect this module creates must actually get cleaned up when combat ends; a round/minute/encounter-duration effect must be left alone (it expires through the system's own duration handling, and deleting it early would be a real correctness bug).
- `summarizeEffect` must never throw on an unrecognized rule-element key — a PF2e content update introducing a new rule key must degrade to a generic label, not break vocabulary building entirely.

```js
/**
 * #914: pure helpers turning an effect's own rule elements/duration into
 * the short, deterministic labels the #909 reasoning model reads (per
 * this feature's spec, Decision 4: "the model chooses among entries by
 * purpose; it never reads raw rules"). No Foundry API surface at all.
 */

const RULE_LABEL_BUILDERS = {
  FlatModifier: (r) => `+${r.selector ?? "stat"}`,
  AdjustModifier: (r) => `${r.selector ?? "stat"} adj`,
  DamageDice: () => "+damage dice",
  TempHP: () => "temp HP",
  Resistance: (r) => `resist ${Array.isArray(r.type) ? r.type.join("/") : (r.type ?? "")}`.trim(),
  RollOption: () => "option",
  ActiveEffectLike: (r) => `${String(r.path ?? "stat").split(".").pop()} mod`,
  AdjustStrike: () => "strike adj",
  Aura: () => "aura",
  Note: () => "note",
  BaseSpeed: () => "+speed",
  Sense: (r) => `sense${r.selector ? `: ${r.selector}` : ""}`,
  ItemAlteration: () => "item alteration",
  Strike: (r) => `grants strike${r.label ? `: ${r.label}` : ""}`,
  CreatureSize: () => "size change",
  FastHealing: () => "fast healing",
  RollTwice: () => "roll twice",
  GrantItem: () => "grants item",
  AdjustDegreeOfSuccess: () => "degree adjustment",
  TokenLight: () => "light",
};

export function summarizeEffect(rules = []) {
  if (!rules.length) return "(no mechanical rules)";
  const labels = rules.map((r) => RULE_LABEL_BUILDERS[r.key]?.(r) ?? r.key);
  return [...new Set(labels)].join(", ");
}

export function effectDurationLabel(duration) {
  if (!duration) return "unknown";
  if (duration.unit === "unlimited") return "unlimited";
  if (duration.unit === "encounter") return "until encounter ends";
  return `${duration.value} ${duration.unit}`;
}

const TIER_0_KEYS = new Set(["FlatModifier", "AdjustModifier", "DamageDice", "AdjustStrike", "BaseSpeed", "Strike"]);
const TIER_1_KEYS = new Set(["Resistance"]);

export function effectRelevanceTier(rules = []) {
  const keys = new Set(rules.map((r) => r.key));
  if ([...TIER_0_KEYS].some((k) => keys.has(k))) return 0;
  if ([...TIER_1_KEYS].some((k) => keys.has(k))) return 1;
  return 2;
}
```

```js
const SELF_EFFECT_VOCABULARY_CAP = 12;

/** #914: the five deterministic checks against an effect's OWN rule
 * elements/duration that decide whether this module can safely apply it
 * to an AI actor unattended — confirmed live against the real
 * pf2e.feats-srd/pf2e.actionspf2e compendia and their linked effects
 * while this plan was written (see
 * tests/fixtures/self-effect-audit-snapshot.json for the full classified
 * population). Returns true (excluded) on ANY hit. */
function isUnsafeSelfEffect(rules) {
  const hasChoiceSet = rules.some((r) => r.key === "ChoiceSet");
  const hasGrantItem = rules.some((r) => r.key === "GrantItem");
  const hasTargetDependency = rules.some((r) => {
    if (r.key === "TokenMark") return true;
    const text = JSON.stringify(r);
    return text.includes("target:") || /@target\b/.test(text);
  });
  const noRules = rules.length === 0;
  return hasChoiceSet || hasGrantItem || hasTargetDependency || noRules;
}

function frequencyLabel(frequency) {
  if (!frequency) return null;
  return `${frequency.max ?? 1}/${frequency.per ?? "day"}`;
}

/** #910/#914: the self-effect vocabulary category — #910's own
 * stance-trait-or-Rage allowlist is replaced here by the full derived
 * filter: any one-action/free item with a resolvable selfEffect is a
 * candidate, excluded only by #910's existing per-turn gates (action
 * type, cost, frequency, already-active, unresolved ChoiceSet on the
 * FEAT item itself), this task's own five effect-level checks, and the
 * reviewed denylist. Still scans both itemTypes.action and
 * itemTypes.feat, unchanged from #910. */
export async function computeSelfEffectVocabularyEntries(actor, actionsRemaining) {
  const scored = [];
  const candidates = [...(actor.itemTypes?.action ?? []), ...(actor.itemTypes?.feat ?? [])];
  for (const item of candidates) {
    const actionType = item.system.actionType?.value;
    if (actionType !== "action" && actionType !== "free") continue;
    const cost = actionType === "free" ? 0 : (item.system.actions?.value ?? 1);
    if (actionType === "action" && cost !== 1) continue;
    if (!item.system.selfEffect) continue;
    if (cost > actionsRemaining) continue;
    const frequencyValue = item.system.frequency?.value;
    if (typeof frequencyValue === "number" && frequencyValue <= 0) continue;
    if (hasUnresolvedChoiceSet(item)) continue;
    if (SELF_EFFECT_DENYLIST.has(item.slug)) continue;

    const effect = await fromUuid(item.system.selfEffect.uuid);
    if (!effect) continue;
    const rules = effect.system?.rules ?? [];
    if (isUnsafeSelfEffect(rules)) continue;
    const duration = effect.system?.duration;
    if (duration?.unit === "hours" || duration?.unit === "days") continue;
    if (actorAlreadyHasEffectFrom(actor, item)) continue;

    const isStance = (item.system.traits?.value ?? []).includes("stance");
    const replacesStance = isStance ? await findActiveStanceEffectId(actor) : null;
    scored.push({
      entry: {
        itemId: item.id, slug: item.slug, name: item.name, cost, replacesStance,
        effectSummary: summarizeEffect(rules),
        durationLabel: effectDurationLabel(duration),
        frequencyLabel: frequencyLabel(item.system.frequency),
      },
      tier: effectRelevanceTier(rules),
    });
  }
  scored.sort((a, b) => a.tier - b.tier);
  return scored.slice(0, SELF_EFFECT_VOCABULARY_CAP).map((s) => s.entry);
}
```

```js
/** #914: effects this module's own AI-actor pipeline created
 * (`executeSelfEffectFeat`'s own `flags[MODULE_ID].agentSelfEffect` tag)
 * whose own duration is `unlimited` would otherwise outlive the
 * encounter they were created in — removed here, once, when combat
 * ends. A round/minute/encounter-duration effect is left alone; it
 * expires through PF2e's own duration handling, and removing it early
 * would be a real correctness bug, not a cleanup. */
export async function cleanupAgentSelfEffects(combat) {
  for (const combatant of combat.combatants ?? []) {
    const actor = combatant.actor;
    if (!actor) continue;
    const toRemove = (actor.itemTypes?.effect ?? []).filter(
      (e) => e.flags?.[MODULE_ID]?.agentSelfEffect === true && e.system?.duration?.unit === "unlimited",
    );
    if (!toRemove.length) continue;
    try {
      await actor.deleteEmbeddedDocuments("Item", toRemove.map((e) => e.id));
    } catch (err) {
      console.error(`${MODULE_ID} | failed to clean up agent self-effects for ${actor.name}:`, err.message);
    }
  }
}
```
